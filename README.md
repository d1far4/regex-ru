# Регулярные выражения в Python для российских данных

Готовые и проверенные тестами регулярные выражения (модуль `re`) для того, что встречается в русских текстах и выгрузках: **номер телефона, ИНН, СНИЛС, ОГРН, КПП, БИК, расчётный счёт, госномер автомобиля, паспорт, почтовый индекс, даты по-русски, суммы в рублях**.

Один файл [`regex_ru.py`](regex_ru.py), только стандартная библиотека, Python 3.8+. Скопируйте его в проект или возьмите нужную строку.

```python
from regex_ru import find_phones, find_inns, find_dates, find_money

text = "ООО «Ромашка», ИНН 7707083893, тел. 8 (912) 345-67-89, договор от 17 ноября 2026 г. на 1 250,50 ₽"
find_phones(text)   # ['+79123456789']
find_inns(text)     # ['7707083893']  — с проверкой контрольной цифры
find_dates(text)    # ['2026-11-17']
find_money(text)    # [1250.5]
```

## Шаблоны

| Что | Регулярное выражение | Пример |
|---|---|---|
| Телефон РФ | `(?:\+7\|8)[\s\-]*\(?(\d{3})\)?[\s\-]*(\d{3})[\s\-]*(\d{2})[\s\-]*(\d{2})` | +7 (912) 345-67-89, 89123456789 |
| ИНН | `\d{10}\|\d{12}` + контрольные цифры | 7707083893 |
| СНИЛС | `(\d{3})[\- ]?(\d{3})[\- ]?(\d{3})[\- ]?(\d{2})` + контрольное число | 112-233-445 95 |
| ОГРН / ОГРНИП | `[15]\d{12}` / `3\d{14}` + контрольная цифра | 1027700132195 |
| КПП | `\d{4}[\dA-Z]{2}\d{3}` | 773601001 |
| БИК | `04\d{7}` | 044525225 |
| Расчётный счёт | `\d{20}` | 40702810900000012345 |
| Госномер | `[АВЕКМНОРСТУХ]\d{3}[АВЕКМНОРСТУХ]{2}\s?\d{2,3}` | А123ВС77 |
| Паспорт РФ | `(\d{2})\s?(\d{2})\s?(\d{6})` | 45 06 123456 |
| Почтовый индекс | `[1-6]\d{5}` | 101000 |
| Дата ДД.ММ.ГГГГ | `(0?[1-9]\|[12]\d\|3[01])\.(0?[1-9]\|1[0-2])\.((?:19\|20)\d{2})` | 01.12.2026 |
| Дата словами | `(\d{1,2})\s+(января\|…\|декабря)\s+(\d{4})` | 17 ноября 2026 г. |
| Сумма в рублях | `(\d{1,3}(?:[  ]\d{3})+\|\d+)(?:[,.](\d{2}))?\s?(?:₽\|руб\.?\|рублей\|р\.)` | 1 250,50 ₽ |

В файле шаблоны окружены `(?<!\d)` и `(?!\d)`, чтобы не находить кусок длинного числа: без этого `\d{10}` найдёт «ИНН» внутри номера счёта.

## Номер телефона

```python
import re

PHONE = re.compile(r"(?<![\d+])(?:\+7|8)[\s\-]*\(?(\d{3})\)?[\s\-]*(\d{3})[\s\-]*(\d{2})[\s\-]*(\d{2})(?!\d)")

PHONE.sub(r"+7 (\1) \2-\3-\4", "звоните 8-912-345-67-89")
# 'звоните +7 (912) 345-67-89'
```

Шаблон принимает пробелы, дефисы и скобки в любом сочетании. Чтобы проверить, что **вся строка** — телефон (например, поле формы), используйте `PHONE.fullmatch(s)`, а не `PHONE.search(s)`.

## Почему регулярного выражения мало для ИНН и СНИЛС

`\d{10}` пропустит и `1234567890`. У ИНН, СНИЛС и ОГРН есть контрольные цифры, их проверяет обычная функция:

```python
from regex_ru import is_valid_inn, is_valid_snils, is_valid_ogrn

is_valid_inn("7707083893")      # True
is_valid_inn("7707083894")      # False — ошибка в последней цифре
is_valid_snils("112-233-445 95")  # True
is_valid_ogrn("1027700132195")  # True
```

Регулярка находит кандидатов в тексте, функция отсеивает случайные числа — так работает `find_inns()`.

## Госномер: кириллица или латиница

В номерах используются только 12 букв: А, В, Е, К, М, Н, О, Р, С, Т, У, Х — те, что пишутся одинаково в двух алфавитах. Если данные пришли из разных систем, в одном номере могут оказаться и русские, и латинские буквы. Перед поиском приведите их к одному алфавиту:

```python
LAT_TO_CYR = str.maketrans("ABEKMHOPCTYX", "АВЕКМНОРСТУХ")
plate = "A123BC77".translate(LAT_TO_CYR)   # 'А123ВС77'
```

## Потренироваться

Готовый шаблон легко скопировать, но в реальных данных всегда находится случай, под который он не подходит. Чтобы научиться писать такие шаблоны самому, я сделал тренажёр на Stepik: **[«Регулярные выражения в Python: 60 задач на реальных данных»](https://stepik.org/a/306981)**. Там телефоны, ИНН, выписки, логи nginx и выгрузки из 1С, каждая задача проверяется автоматически. Первый урок бесплатный, весь курс — 490 ₽.

Две задачи в том же духе — решите, не подглядывая в `regex_ru.py`:

1. Из строки `«Оплата 12.03.2026, возврат 1.4.2026»` получите `['2026-03-12', '2026-04-01']` одним `re.sub` или `re.findall`.
2. Замаскируйте номер карты: `2200 1234 5678 9010` → `2200 **** **** 9010`.
